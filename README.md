# Kingsfall

A retro 8-bit turn-based strategy game for your browser and phone.

Pick an era (Ancient or Napoleonic), choose a faction, and battle 1 to 3 rival empires.
Found cities, train troops, merge them into companies and battalions, and capture every rival city to win.

Open `index.html` in any browser to play, or visit the GitHub Pages link for this repository.
